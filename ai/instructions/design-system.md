# Design System Direction

## Aire visual

Lujo silencioso, composicion editorial, contraste controlado y ritmo amplio.

## Paleta base

- Negro profundo: fondo principal.
- Carbon elevado: superficies.
- Hueso: tipografia principal.
- Gris humo: soporte y texto secundario.
- Dorado apagado: acento de foco y jerarquia.

## Tipografia

- Serif elegante para manifiesto, identidad y titulares clave.
- Sans precisa para UI, estructura y lectura funcional.

## Comportamiento de superficies

- Bordes finos y discretos.
- Sombras profundas pero suaves.
- Contraste legible sin brillo agresivo.
- Espacios amplios para reforzar claridad.

## Botones y estados

- Primario: dorado apagado con texto oscuro.
- Secundario: transparente con borde sutil.
- Hover/focus: refinado, no estridente.
- Estados de feedback coherentes con tokens (`success`, `warning`, `danger`, `info`).

## Que hace que algo se sienta El Ojo Negro

1. Jerarquia clara sin ruido.
2. Copy breve con peso.
3. Materialidad sobria, no plastica.
4. Identidad consistente entre landing y producto.
